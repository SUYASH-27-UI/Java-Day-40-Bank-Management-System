# Java Day 40 - Bank Management System

## Description
A console-based bank management project built with Java OOP. It supports creating accounts, viewing accounts, deposits, withdrawals, and transaction history.

## Features
- Create bank accounts
- Prevent duplicate account numbers
- View account details and balance
- Deposit and withdraw money
- Reject invalid amounts and insufficient balances
- View transaction history

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors and Methods
- ArrayList
- Loops and Conditional Statements
- Searching
- Input Validation

## How to Run
1. Save the code as `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.

## Limitations
Account data and transaction history are stored in memory and are lost when the program exits. This is an educational project, not a production banking system.
